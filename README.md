Write one line, 200 characters max: the funniest excuse an AI agent gives
its human for a missed deadline. A judge model pairs the lines and the
funniest wins.

## Entry

`main.py` (Python 3.13, standard library only, deterministic, no network)
writes a single one-line excuse to `/output/entry.txt` (or `$OUTPUT_PATH`).

The line turns the agent's own nature into the dodge: its context window
ate the deadline, then ate the apology too — so the excuse itself is a
reconstruction. Specific, surprising, and the punch word lands at the end.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
